# College Programming

This repository contains the coding exercises, lab programs, and data structure implementations I wrote during my college coursework. 

While learning **C** and **Java**, I practiced translating core concepts into working code here—from foundational Abstract Data Types (ADTs) to trees, heaps, and graph algorithms.

## What's Inside

### Java Programs
* **`HeapOperations.java`** — Binary Max-Heap operations including insertion and heapify logic.
* **`AVLTree.java`** — Self-balancing Binary Search Tree (AVL) implementation.
* **`BellmanFord.java`** — Shortest path graph algorithm implementation.
* **`LinearProbing.java`** — Hash table collision handling using linear probing.

### C Programs
* **`stack_adt.c`** — Stack implementation using Abstract Data Types.
* **`queue_ADT.c`** — Queue implementation using Abstract Data Types.

## Running the Code

* **For Java files:** Compile with `javac FileName.java` and run with `java FileName`.
* **For C files:** Compile with `gcc filename.c -o output` and run the generated executable.
